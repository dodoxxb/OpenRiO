Contributing to OpenRiO
=========================

Please report the weight/config hashes, model state (raw, EMA or calibrated),
dataset split, angle convention, AP definition and complete evaluation size.
Keep reproduction and optimization comparisons separate. Match the source
checkpoint, exposure budget and inference cost when proposing an improvement.
Provide an ordinary-training or simpler-method control as appropriate.

Small subsets can diagnose behavior; they cannot replace complete-set claims.
Report unsuccessful comparisons and resource-admission failures separately.
Do not truncate dense ground truths to pass a memory test. Preserve the
upstream method credit and state which code or ideas were adapted.

Useful first contributions are portable training recipes, independent seed
runs, another-host installation checks and isolated end-to-end benchmarks.
